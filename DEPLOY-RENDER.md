# AI StudyMate — Render deployment checklist

## 1. Put the project on GitHub

Create a new GitHub repository and upload the contents of this `AI-StudyMate` folder.

Do **not** upload `.env` or any real OpenAI API key.

## 2. Create the Render services

In Render:

1. Choose **New → Blueprint**.
2. Select the GitHub repository.
3. Render reads `render.yaml` and creates:
   - `ai-studymate` Node web service
   - `ai-studymate-db` PostgreSQL database
4. The web service uses `npm install` to build and `npm start` to run.

## 3. Add your OpenAI key

Open the `ai-studymate` web service → **Environment** → **Environment Variables** and add:

```text
OPENAI_API_KEY = your_real_openai_api_key
```

`JWT_SECRET` is generated by the Blueprint and `DATABASE_URL` is connected to the Postgres database automatically.

## 4. Deploy

After deployment, open the public Render URL. Students can register their own accounts and use the app from their phones or laptops.

## 5. Test

Open:

```text
/health
```

A healthy deployment returns JSON with `ok: true` and shows whether the database and AI are configured.

Then test:

- Register a new student
- Log in
- Add/delete a subject
- Create/complete/delete a task
- Ask AI a question
- Add/use flashcards
- Complete a quiz
- Check progress

## Security

Keep `OPENAI_API_KEY` only in Render's Environment settings. Never put it into `public/index.html`, `public/app.js`, or any GitHub repository.
